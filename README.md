# Dating Liquidity Calculator

**Калькулятор дейтинг-ликвидности** — интерактивный одностраничный инструмент для объективной оценки рыночной стоимости профиля на дейтинг-платформах.

>> посчитать прямо в браузере: https://gcodegspot.github.io/dating-calculator-2.0/

---

## Математическая модель

Итоговый **Dating Liquidity Index (DLI)** рассчитывается мультипликативно:

```
DLI = max(minDli, ∏(k_i)) × 100%
```

В модель заложена многоуровневая воронка **Drop-Funnel** (Свайпы ➔ Мэтчи ➔ Диалоги ➔ Оффлайн-свидание):
- **Свайпы на мэтч**: `swipes_to_match = 100 / (15% × DLI)`.
- **Мэтчи на 1 свидание**: конверсия из мэтча в реальную встречу напрямую зависит от привлекательности анкеты и стиля общения (от ~15–20 мэтчей у *Любимчиков алгоритмов* до ~70–100 мэтчей в тире *Придется попотеть*).
- **Стиль переписки / Опенер**: опциональный параметр первого сообщения (контекстный вопрос $k = 1.15$, дефолтный шаблон $k = 0.85$, агрессивный подкат $k = 0.50$, молчаливое ожидание $k = 0.40$ для мужчин / $1.00$ для женщин).
- **Итого свайпов на свидание**: `swipes_per_date = swipes_to_match × matches_to_date`.

| DLI | Tier | Описание | Мэтчей на свидание (м/ж) |
|-----|------|----------|--------------------------|
| ≥ 110% | **Любимчик алгоритмов [AAA]** | Дефолтный карт-бланш платформы | ~15–22 / ~3–6 |
| 75–109% | **Стабильный нормис [A]** | Стабильная комфортная воронка | ~25–35 / ~7–10 |
| 45–74% | **Дейтинг-трудоголик [B]** | Ощутимое сопротивление платформы | ~40–60 / ~11–16 |
| 25–44% | **Придется попотеть [C]** | Повышенное сопротивление алгоритмов | ~65–100 / ~18–28 |
| 10–24% | **Нишевый артхаус [D]** | Экстремально высокий CAC (у женщин floor на этом тире) | ~120–250 / ~30–50 |
| < 10% | **Мёртвая петля алгоритма [!!!]** | Нулевая ликвидность в масс-маркете (только муж.) | ∞ |


Данные носят **развлекательный характер**. Математическая модель намеренно упрощена и не претендует на точность. DLI — это пародийный продуктовый инструмент, вдохновлённый реальными паттернами дейтинг-платформ и созданный дейтинг-аутстаффом.
